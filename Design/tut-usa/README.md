# TUT USA normalized design package

This folder is the canonical processed-design location for TUT USA rebuild work.
The source folder `Design/sample-website-tut/` is immutable input evidence and is
never edited in-place.

## Storage map

```text
design/tut-usa/
  README.md
  generated/                            # generated contracts/page-tree artifacts
  templates/{template-slug}/            # normalized template package (future REB-02)
    source-ref.md
    normalized.html
    screenshot-reference.png
    capture-evidence.png
    assets-manifest.json
    test-cases.md
  components/{component-group-slug}/    # normalized component-group package (future REB-02)
    source-ref.md
    normalized.html
    screenshot-reference.png
    capture-evidence.png
    assets-manifest.json
    test-cases.md
  assets/
    images/
    fonts/
    media/
    styles/
```

## Source of truth and references

- Template source libraries: `Design/sample-website-tut/template-libs/`
- Component source libraries: `Design/sample-website-tut/component-libs/`
- Contracts/page-tree generated by backend lane: `Design/tut-usa/generated/`
- Inventory and evidence status for REB-01: `df/artifacts/REB-01/design/inventory.md`

## Rules

- Do not mutate files under `Design/sample-website-tut/`.
- Screenshot evidence is currently referenced from source `screen.png` files; REB-02
  may additionally copy canonical snapshots into this folder after browser capture.
- Remote assets/fonts must be captured through browser automation (REB-02) before
  runtime import into DAM/public bundles.
- Browser-captured static CSS files also live under `assets/styles/` so normalized
  HTML can point to local stylesheet references without depending on remote CDN CSS.
