## Reproduce

1. Open `/content`.

**Expected:** The breadcrumb reflects the real location: Sites › <current site title> › Pages, with working links.

**Actual:** It reads "Sites › Corporate Portal › Pages", where the site link is `href="#"` and matches no real site.

## Root cause

`frontend/apps/admin/src/app/(admin)/content/page.tsx:337` contains the literal `Corporate Portal`.

## Acceptance criteria

- [ ] AC1: The breadcrumb shows the title of the site being browsed (derived from the current path), and each item links to its level.
- [ ] AC2: At the root (no site selected), the breadcrumb is "Sites › Pages".
- [ ] AC3: A regression test reproduces the bug. It fails before the fix and passes after it.
