# BUG-005 — Material Symbols icon font never loads; icon buttons show ligature text

| Field | Value |
|---|---|
| Type | Bug |

| Severity | Major |
| Area | Admin UI (cross-cutting) |

> Status is tracked only in [`backlog/BOARD.md`](../BOARD.md).

## Reproduce

1. Open `/pim/import`, `/pim` or `/pim/schema`.

**Expected:** Icon glyphs are shown.

**Actual:** Literal text such as `upload_file` or `arrow_back` is shown.

## Root cause

Many pages use `className="material-symbols-outlined"`, but no layout or global CSS under `frontend/apps/admin/src` loads the font.

## Acceptance criteria

- [ ] AC1: No admin page renders Material Symbols ligature text. Either the font is loaded once in the admin root layout, or these usages are replaced with the icon components used elsewhere in `@flexcms/ui`. Record which approach you chose, and why, in the Log.
- [ ] AC2: The approach works offline, in the production build and in CI. There is no runtime dependency on a third-party CDN unless the admin already relies on one.
- [ ] AC3: A regression test reproduces the bug. It fails before the fix and passes after it.
