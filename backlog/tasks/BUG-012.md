# BUG-012 — Product asset links accept DAM paths that do not exist

> Status is tracked only in [`backlog/BOARD.md`](../BOARD.md).

## Reproduce

1. Link a product to the asset path `/content/dam/does-not-exist.png` through the PIM API.

**Expected:** To be decided: reject with 422, or accept and flag it as a broken reference.

**Actual:** The link is accepted silently.

## Root cause

`ProductAssetRefService.link()` only checks for duplicate links. PIM and the CMS/DAM are isolated on purpose: separate DB, no CMS `DataSource`.

## Acceptance criteria

- [ ] AC1: The behaviour decided in refinement is implemented without PIM querying the CMS database directly. For example, it calls the DAM API or checks asynchronously.
- [ ] AC2: The decision is recorded in `docs/architecture/DECISIONS.md`.
