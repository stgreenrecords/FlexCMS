# BUG-006 — Component Registry pagination changes the page number but not the rows

> Status is tracked only in [`backlog/BOARD.md`](../BOARD.md).

## Reproduce

1. Open `/components`.
2. Click **Next**.

**Expected:** The indicator shows "2 of N", and the table shows the next 12 components.

**Actual:** The indicator changes, but the rows stay the same.

## Root cause

`frontend/apps/admin/src/app/(admin)/components/page.tsx` computes `totalPages` from `PAGE_SIZE = 12`, but lines ~650 and ~820 render `filteredComponents.map(...)` without slicing by `currentPage`.

## Acceptance criteria

- [ ] AC1: Both the table and the grid views show exactly the components of the current page (12 per page).
- [ ] AC2: Changing the filter resets to page 1, and the indicator reflects the filtered total.
- [ ] AC3: A regression test reproduces the bug. It fails before the fix and passes after it.
