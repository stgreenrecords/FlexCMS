# BUG-014 — Reference site drops asset and reference fields of many components

|---|---|

> Status is tracked only in [`backlog/BOARD.md`](../BOARD.md).

## Reproduce

1. Run the component-editing sweep against the tut-usa sample site (Selenium REB-26 suite, or its Playwright port).

**Expected:** Every asset field renders an `<img>`/media element, and every reference field renders a working link.

**Actual:** 9 image-like asset fields produce no `<img>`, and 18 of 30 reference fields produce no anchor. Form components render as read-only previews.

## Root cause

The renderers do not map these schema fields. Interactive forms are covered separately by ECMS-58.

## Acceptance criteria

- [ ] AC1: Every component whose `dataSchema` has an asset field renders the asset on the site.
- [ ] AC2: Every reference/link field renders an anchor to the resolved URL.
- [ ] AC3: Form interactivity is out of scope (ECMS-58).
- [ ] AC4: A regression test reproduces the bug. It fails before the fix and passes after it.
