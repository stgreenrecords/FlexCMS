# BUG-003 — Dashboard "Active Sites" undercounts

> Status is tracked only in [`backlog/BOARD.md`](../BOARD.md).

## Reproduce

1. `GET http://localhost:8080/api/admin/sites` returns 5 active sites.
2. Open `/dashboard`.

**Expected:** The **Active Sites** card reads 5.

**Actual:** It reads 1.

## Root cause

`frontend/apps/admin/src/app/(admin)/dashboard/page.tsx:84` counts distinct `siteId` values among the first 50 nodes of `/api/author/content/list?size=50` instead of reading `/api/admin/sites`.

## Acceptance criteria

- [ ] AC1: The Active Sites card shows the number of sites with `active: true` from `GET /api/admin/sites`.
- [ ] AC2: A regression test reproduces the bug. It fails before the fix and passes after it.
