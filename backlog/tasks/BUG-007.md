# BUG-007 — Preview of a never-published page opens in Live mode and spins forever

| Field | Value |
|---|---|
| Type | Bug |
| Priority | P2 |
| Severity | Major |

| Original IDs | FINDING-08 |
| Depends on | — |

> Status is tracked only in [`backlog/BOARD.md`](../BOARD.md).

## Reproduce

1. In the Content Tree, open the row menu of a DRAFT page and click **Preview**.

**Expected:** Preview opens in Draft mode. If Live mode is chosen for an unpublished page, it says the page is not published.

**Actual:** It opens in Live mode against `:8081` and shows "Loading preview..." forever.

## Root cause

`frontend/apps/admin/src/app/preview/page.tsx:96` falls back to `'live'` unless the URL has `mode=draft`.

## Acceptance criteria

- [ ] AC1: Preview defaults to Draft mode unless `mode=live` is explicitly requested.
- [ ] AC2: In Live mode, a 404 from publish shows a "This page is not published" empty state with a button to switch to Draft; a network error shows an error state. The page never spins indefinitely.
- [ ] AC3: A regression test reproduces the bug. It fails before the fix and passes after it.
